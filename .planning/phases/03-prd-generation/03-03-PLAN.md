  <action>Create scripts/prd/retrieval.py with iterative search:

Functions to implement:
1. iterative_retrieval(
     initial_keywords: list[str],
     db_path: Path,
     client,  # Anthropic client
     model: str,
     max_iterations: int = 5,
     min_new_keywords: int = 2,
   ) -> tuple[list[dict], list[str]]:
   - Initialize: searched_keywords = set(initial_keywords), pending = initial_keywords, all_results = []
   - Loop for max_iterations:
     - If pending empty: break
     - query = " ".join(pending)
     - results = search_wiki(db_path, query, limit=10)
     - Deduplicate: filter results by path not in all_results
     - all_results.extend(deduped)
     - result_text = "\n".join([r["snippet"] for r in results])
     - new_keywords = extract_keywords_from_results(result_text, searched_keywords, client, model)
     - pending = [k for k in new_keywords if k not in searched_keywords]
     - searched_keywords.update(new_keywords)
     - If len(pending) < min_new_keywords: break (convergence)
   - Return (all_results, list(searched_keywords))

2. extract_keywords_from_results(
     result_text: str,
     already_searched: set[str],
     client,
     model: str,
   ) -> list[str]:
   - Load suggest.md prompt
   - Build message: prompt + "\n\n## Search Results:\n" + result_text + "\n\n## Already searched:\n" + str(already_searched)
   - Call Anthropic API
   - Parse JSON keyword list from response
   - Return keywords (limit to 10 per iteration)

Use patterns from compiler.py for LLM calls. Import search_wiki from scripts.search.

Implement tests in tests/test_prd.py::TestIterativeRetrieval with mock search results.
</action>

  </verify>
  <done>Iterative retrieval loop works, convergence detected, deduplication applied, tests pass</done>
</task>
