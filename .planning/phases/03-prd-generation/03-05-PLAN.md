  <action>Create scripts/prd/generator.py with orchestration:

Functions to implement:
1. assemble_prd_content(
     collection: RequirementCollection,
     search_results: list[dict],
     conflicts: list[Conflict],
     assessment: AssessmentReport,
   ) -> dict:
   - Extract requirements from collection.collected_requirements
   - Build context dict with:
     - title: requirements.get("title")
     - background: requirements.get("background") + conflict resolutions
     - user_stories: requirements.get("user_stories", [])
     - flows: requirements.get("flows", [])
     - entities: extracted from search_results
     - concepts: extracted from search_results
     - risks: assessment.risks
     - costs: assessment.costs (for relevant sections)
     - references: format_references(search_results)
   - Return context dict for template rendering

2. generate_prd(
     collection: RequirementCollection,
     db_path: Path,
     wiki_dir: Path,
     client,
     model: str,
     output_path: Path | None = None,
   ) -> Path:
   - Get suggestions from collection.get_collected_requirements()
   - Run iterative_retrieval() for KB content
   - Run detect_conflicts() for validation
   - Run assess_risks() for assessment
   - Assemble context with assemble_prd_content()
   - Render PRD with render_prd(collection.template_type, context)
   - Determine output path: output_path or wiki_dir / "prd" / f"{title}.md"
   - Write markdown to output path
   - Return output path

3. validate_prd_structure(prd_content: str, template_type: str) -> bool:
   - Check all required sections present
   - Verify markdown syntax
   - Return True if valid, False otherwise

Implement tests in tests/test_prd.py::TestPRDStructure with mock fixtures.
